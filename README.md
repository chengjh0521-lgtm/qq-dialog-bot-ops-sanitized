# QQ 对话机器人：安全运维发布包

这是从内部项目中经过白名单筛选后发布的运维基础包，用于保留 QQ 机器人、环境变量和邮件通知的通用部署信息。

## 安全边界

本仓库**不包含**策略、算法、信号、仓位计算、行情采集、交易日历、数据契约、回测、策略接口、测试数据、运行日志、数据库、Excel 台账或任何 `.env` 内容。

仓库中的示例配置全部为空值；部署时请在本机创建 `.env`，不要将它提交到 Git。

## 初始化

Windows PowerShell 中执行：

```powershell
.\setup.ps1
```

随后参考 `.env.example` 创建本机 `.env` 并填写 QQ 开放平台与 QQ 邮箱授权信息。

## 通用邮件通知

这个发布包提供了环境变量模板和依赖清单，供独立的 QQ 机器人或通知程序使用。业务策略与业务数据必须保留在受控的内部仓库中。
