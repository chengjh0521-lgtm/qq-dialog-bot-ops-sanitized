# QQ 对话机器人：安全运维发布包

这是从内部项目中经过白名单筛选后发布的协作层参考实现。它展示通讯、信息、研发与算法部门之间的调用边界，以及信息部门的 SQLite 数据读写方式。

## 安全边界

本仓库**不包含**任何策略、算法、信号产生规则、指标、参数、仓位计算、行情采集实现、交易日历、回测、测试数据、运行日志、数据库文件、Excel 台账或任何 `.env` 内容。

`public_reference/` 中的代码是从零编写的可运行参考层，不是内部业务源码。它只接收由受控算法服务产生的“不透明信号”，负责校验、传递和存储；绝不实现或推导信号。

仓库中的示例配置全部为空值；部署时请在本机创建 `.env`，不要将它提交到 Git。

## 初始化

Windows PowerShell 中执行：

```powershell
.\setup.ps1
```

随后参考 `.env.example` 创建本机 `.env` 并填写本机配置。运行协作层示例：

```powershell
uvicorn public_reference.communication.api:app --reload
```

访问 `http://127.0.0.1:8000/docs` 可查看接口。示例数据库默认写入本机 `runtime/operations.db`，并被 Git 忽略。

## 部门协作边界

```text
通讯部门 -> 信息部门：查询持仓、录入人工操作
研发部门 -> 信息部门：写入分钟行情、投递不透明信号
信息部门 -> 通讯部门：返回持仓与操作记录
算法部门 -> 研发部门：仅输出不透明信号（算法在本仓库外）
```

详细的请求和数据模型见 `public_reference/README.md`。业务策略与真实业务数据必须始终保留在受控的内部仓库中。
